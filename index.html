FONCTIONNALITÉS

Un écosystème complet
pour la vie associative

Du parcours étudiant à la gouvernance administrative, Orbit connecte tous les acteurs.

Inscription en ligne

Inscription instantanée à un ou plusieurs clubs depuis n'importe quel appareil. Plus de formulaires papier.

Agenda intelligent

Détection automatique des conflits d'horaires, rappels 24h avant, synchronisation calendriers.

Notifications ciblées

Push, email, SMS. Communication personnalisée selon vos centres d'intérêt et engagement.

Statistiques temps réel

Tableaux de bord dynamiques pour les responsables : taux de présence, fréquentation, engagement.

SSO & Sécurité

Connexion via l'ENT universitaire, conformité RGPD, chiffrement des données, hébergement souverain.

Accessibilité & i18n

Interface multilingue, compatible lecteurs d'écran, mode contraste élevé, design inclusif.

ARCHITECTURE

Une stack moderne et souveraine

Technologies open-source, hébergement local, conformité RGPD et interopérabilité ENT.

Backend

API REST Node.js / Express, base PostgreSQL, Redis pour le cache, files BullMQ pour les notifications asynchrones.

Node.js PostgreSQL Redis JWT

Frontend

Application web responsive React 18 + Vite, application mobile React Native, design system tokens partagés.

React 18 Vite React Native PWA

Sécurité

SSO ENT via SAML/OAuth, chiffrement AES-256, audit logs, anonymisation RGPD, sauvegardes chiffrées 3-2-1.

SSO RGPD AES-256 OAuth 2
